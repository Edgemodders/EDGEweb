// The EDGE platform · screenshots the site waits for

Image dossier.

Every screenshot a wiki page or the platform page still shows as a placeholder. The yellow rows are of the running game, so only you can take them. The cyan rows are of the editor or the desktop: a Claude session takes those by script and they leave this list by themselves.

How to hand one in. Take the shot at any size, save it as a PNG under the file name on its row, into the inbox:

Then say in the chat that the inbox has pictures. The session checks each for personal details (user names in paths, account names, keys, email addresses), resizes it, moves it to the folder on its row and fills the placeholder. A name that differs is fine: it asks which shot it is.
