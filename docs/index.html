01The edgemodders community

Modding Cyberpunk 2077 used to mean years of learning file formats, scripting languages and toolchains. EDGEmodders is a new community building AI-first tools, so you describe the mod you want in plain words and build it together with an AI assistant. You don't need to code or know modding to start.

02Modding, then and now

Night City has one of the best modding communities in gaming. It's also one of the hardest to join. A good idea for a mod usually stalls at the first file format.

Before
  • Learn WolvenKit, CR2W files, archives and hashes
  • Learn redscript, Lua, TweakDB records and YAML tweaks
  • Pack, copy files by hand, restart the game, repeat
  • Fight load orders and conflicts you can't see
  • Ask on a forum and wait
With EDGEmodders
  • Say what you want: "make the Mantis Blades glow cyan"
  • An assistant reads the game files as plain text and finds what to change
  • It writes the change, packs it and deploys it for you
  • You see the result in game and say what to tweak next
  • Every step is visible, and every deploy can be undone

03The loop

Every EDGEmodders tool exposes what it does as text and as calls an AI agent can make. Here's a session with REDagent, the assistant inside the game:

> you

Make a mod that shows a warning when V's health drops below 30%.

> redagent
01 gameapi_lookup player health found the health functions 02 write low-health/main.mjs you pressed Allow 03 apps low-health loaded by hot reload 04 logs low-health running, no errors

Done. Your low-health warning is running. Take some damage to see it, or press Undo to remove it.

// Simplified from REDagent's in-game test on 2026-10-12. The tool names are REDagent's real tools.

04The toolkit

Open-source toolkits that work alone and work better together. Five of them cover the whole life of a mod. Each one has its own docs site and a section in the wiki.

REDagent New
The modding agent · powered by Claude

An AI assistant inside Cyberpunk 2077. Ask for a mod in a chat window over the game, and REDagent writes it, runs it, reads its log, checks the game's answers and fixes what's wrong, while you play. Every change is shown to you first and can be undone. Uses your own Anthropic API key.

Status: writes and fixes mods in game; early developer build
WikiDocsGitHub
REDcode
The editor

A Cyberpunk 2077 modding IDE built on VS Code. Browse the game's files, edit them, see textures and meshes, hear sounds and pack your mod, with an AI assistant working beside you.

Status: 0.9.0 on the VS Code Marketplace and Open VSX (preview)
WikiDocsGitHub
REDdeck
The mod manager

One list of mods and four verbs: add, on/off, deploy, remove. Every deploy can be undone, and REDdeck shows conflicts inside mod archives, which file-level managers can't see.

Status: 0.26.3 on the VS Code Marketplace and Open VSX (preview); in daily use
WikiDocsDesignGitHub
REDbridge
The engine & AI bridge

Runs WolvenKit's proven C# engine as a local service. The same calls power REDcode and an MCP server, so AI assistants like Claude can browse archives, convert files and pack mods directly.

Status: 0.8.0 released; REDcode and REDdeck fetch it for you
WikiDocsGitHub
REDnode
The live runtime

Script Cyberpunk 2077 in TypeScript and JavaScript with npm, and build in-game HTML overlay apps. Mods attach to the running game, reload without a restart, and can be debugged while the game runs.

Status: 0.23.1. Overlay apps, Node mods, the game API, TweakDB, spaces and the MCP server pass in game; installs from source
WikiDocsDesignGitHub

More tools

Specialist toolkits built on the five above.

EDGEbuilder
The world builder

Build in Night City from inside the game. Search the game's own props, drop them where you look, and move, turn and scale them with a gizmo and a free camera.

Status: 0.3.2 released. Browse, drop, position and the editor camera passed in game; arrange and bake are planned
WikiDocsGitHub
EDGEwave
The sound studio

A sound studio for Cyberpunk 2077 modding that works beside REDcode. Open any game sound, cut, fade and shape it, and save it into your mod.

Status: in development; the sound editor is in hand testing, not released yet
WikiDocsGitHub
EDGEmat
The material editor

Pick a jacket, click a layer, choose a colour and see it on the model. Or just tell an AI assistant "make this jacket red".

Status: planned; the design is done, no code yet
WikiDocsGitHub
EDGEkit
The editor app

The EDGEmodders editor: one app with every EDGE tool built in. Today its extension pack installs REDcode, REDdeck and the HUD theme in VS Code in one go.

Status: extension pack 0.1.0 available (preview); the EDGEkit app is being built
WikiDocsGitHub

05What we stand for

Anyone can mod

Ideas matter more than syntax. If you can describe a mod, you should be able to make one.

You stay in control

AI does the busywork in the open. Every file is readable, every change is visible, every deploy can be undone.

Everything is text

Game files as JSON, tweaks as YAML, scripts as TypeScript. Anything a person can see, an assistant can read, and the other way round.

Build on the community

We work with WolvenKit, RED4ext, Cyber Engine Tweaks, redscript, ArchiveXL and TweakXL, not against them, and we credit the people who built them.

Open source

MIT where we can, GPL-3.0 where WolvenKit requires it. Read it, fork it, improve it.

Veterans welcome

Experienced modders are the people who make this work. AI makes your knowledge go further, and helps you teach the next wave.
