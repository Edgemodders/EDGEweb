01The edgemodders community

Modding Cyberpunk 2077 used to mean years of learning file formats, scripting languages and toolchains. EDGEmodders is a new community building AI-first tools, so you describe the mod you want in plain words and build it together with an AI assistant. You don't need to code or know modding to start.

02Modding, then and now

Night City has one of the best modding communities in gaming. It's also one of the hardest to join. A good idea for a mod usually stalls at the first file format.

Before
  • Learn WolvenKit, CR2W files, archives and hashes
  • Learn redscript, Lua, TweakDB records and YAML tweaks
  • Pack, copy files by hand, restart the game, repeat
  • Fight load orders and conflicts you can't see
  • Ask on a forum and wait
With EDGEmodders
  • Say what you want: "make this jacket red"
  • An assistant reads the game files as plain text and finds what to change
  • It writes the change, builds the mod and, with your OK, puts it in your game
  • You see the result in game and say what to tweak next
  • Every step is visible, and what goes into your game can be taken out again

03The loop

Every EDGE tool shows its work as plain text, and lets an AI assistant press the same buttons you can. That is what lets an assistant build a mod with you. Here is a session with REDagent, the assistant inside the game:

> you

Make a mod that shows a warning when V's health drops below 30%.

> redagent
01 gameapi_lookup player health found the health functions 02 write low-health/main.mjs you pressed Allow 03 apps low-health loaded by hot reload 04 logs low-health running, no errors

Done. Your low-health warning is running. Take some damage to see it, or press Undo to remove it.

04The toolkit

Open-source toolkits that build on each other. Five of them cover the whole life of a mod, and two AI assistants work through them. Each one has its own docs site and a section in the wiki. New here? Your first hour says which to install first.

// Preview means released and usable, but young. The VS Code Marketplace and Open VSX are the two stores that editor add-ons (extensions) install from.

REDagent New
The assistant in the game · powered by Claude

An AI assistant inside Cyberpunk 2077. Ask for a mod in a chat window over the game, and REDagent writes it, runs it, checks that it works and fixes what's wrong, while you play. Every change is shown to you first and can be undone. Uses your own Anthropic API key.

Status: 0.4.1 released for game 2.5, on Nexus Mods and GitHub. Writes and fixes mods in the game, tested in the game. Needs REDnode, and an Anthropic API key that you pay for per use
WikiDocsGitHub
EDGEchat
The assistant at your desk · for Claude Code

A free add-on for Claude Code, Anthropic's AI assistant, that makes it a modding assistant. It teaches Claude how Cyberpunk mods are made and connects it to the running game, the game's files, your mods and their materials. Ask for a mod in plain words. The EDGE tools ask you before anything changes your game.

Status: 0.1.1 released for game 2.5. Needs a Claude plan that includes Claude Code. Connects REDnode, REDcode, EDGEdeck and EDGEmat; quests, quickhacks and sounds are not connected yet
WikiDocsGitHub
REDnode
The part in the game

The part of EDGE that runs in the game while you play. It lets mods load, change and reload without a restart, and draws their windows over the game. REDagent and EDGEbuilder run on it. Mod makers write for it in JavaScript and TypeScript.

Status: 0.62.4 released for game 2.5, on Nexus Mods and GitHub. You install it like any mod. What players use was tested in the game. Optional UI Tools, Sound Tools and Admin Tools packs
WikiDocsDesignGitHub
EDGEdeck
The mod manager

A mod manager, like Vortex. One list of mods: switch them on and off, then press Deploy to put them in the game. Every deploy can be undone. It also shows when two mods change the same thing inside their files, which most mod managers can't see.

Status: 0.31.0, a preview, on the VS Code Marketplace, Open VSX and Nexus Mods, and built into EDGEkit. Its developer uses it every day
WikiDocsDesignGitHub
REDcode
The editor

An editor for the game's files, built on VS Code, Microsoft's free code editor. Browse the game's files, change them, see textures and 3D models, hear sounds and build your mod, with an AI assistant working beside you.

Status: 0.10.9, a preview, on the VS Code Marketplace and Open VSX, and built into EDGEkit. It can swap your mod into the running game through REDnode
WikiDocsGitHub
REDbridge
The file engine

The part that reads and writes the game's files, using WolvenKit's own code. The other tools and the AI assistants all go through it. You never install or open it yourself.

Status: 0.12.1 released for game 2.5. EDGEdeck, REDcode and REDnode download it for you
WikiDocsGitHub

More tools

Specialist toolkits built on the five above.

EDGEbuilder
The world builder

Build in Night City from inside the game. Search the game's own objects and people, drop one where you look, and move, turn and scale it by dragging its handles, with a free camera.

Status: 0.10.9, a public preview for game 2.5, on Nexus Mods and GitHub. Place objects and people in the running game, arrange and save them as scenes, and bake a scene into a mod that stays in the world. People are not baked yet. Needs REDnode
WikiDocsGitHub
EDGEwave
The sound studio

A sound studio that works beside REDcode. Find any game sound, cut, fade and mix it, and put your version into your mod. Its voice tools make new sounds and spoken lines through ElevenLabs, with your own key.

Status: 0.2.0, a preview, on the VS Code Marketplace, Open VSX and Nexus Mods, and built into EDGEkit. Replaced, silenced and new sounds were heard in the game. Voiced quest lines are not there yet. Needs REDcode
WikiDocsGitHub
EDGEmat
The material editor

Pick a jacket, click a layer, choose a color and see it on the model. Or just tell an AI assistant "make this jacket red".

Status: 0.3.2, a preview, on the VS Code Marketplace and Open VSX, and built into EDGEkit. Recolors, and new materials made from your words, were seen in the game. It tells you which in-game item to give V to see your change
WikiDocsGitHub
EDGEquest
The quest maker

Read any of the game's quests in plain words: its steps, its choices, who says what. Then write your own as a short story, with places, choices and music, and EDGEquest makes the game's quest files from it.

Status: 0.1.1, a preview for game 2.5, on the VS Code Marketplace, Open VSX and Nexus Mods, and built into EDGEkit. Small quests with choices and branches were played in the game. For now a quest has V alone, with subtitles and no voices, starts when a save loads, and one place was tested
WikiDocsGitHub
EDGEhack
The quickhack editor

Open any of the game's quickhacks and read every tier in plain words. Change its costs, texts and effects, or make new quickhacks with effects and icons of your own, and try them in the running game.

Status: 0.1.2, a preview for game 2.5, on Open VSX and Nexus Mods, and built into EDGEkit. Not on the VS Code Marketplace yet. What changes the game was tested in the game. Needs REDcode
WikiDocsGitHub
EDGEkit
The editor app

The EDGEmodders editor: one free app for Windows with the EDGE editor tools built in. It installs Claude Code at its first start, if you agree. Already use VS Code? Its extension pack installs the tools there in one go. The tools that run in the game (REDnode, REDagent, EDGEbuilder) install separately.

Status: the app 1.140.6, a preview for Windows; the extension pack 0.6.0, a preview
WikiDocsGitHub

05What we stand for

Anyone can mod

Ideas matter more than syntax. If you can describe a mod, you should be able to make one.

You stay in control

AI does the busywork in the open. Every file is readable, every change is visible, every deploy can be undone.

Everything is text

Game files, game values and scripts all open as plain text, so you and the assistant can read any of it. Anything a person can see, an assistant can read, and the other way round.

Build on the community

We work with WolvenKit, RED4ext, Cyber Engine Tweaks, redscript, ArchiveXL and TweakXL, not against them, and we credit the people who built them.

Open source

MIT where we can, GPL-3.0 where WolvenKit requires it. Read it, fork it, improve it.

Veterans welcome

Experienced modders are the people who make this work. AI makes your knowledge go further, and helps you teach the next wave.
