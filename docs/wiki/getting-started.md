# Getting <span class="y">started</span>

EDGE is a family of tools. You don't need all of them. Start from what you want to do.

## I want to...

| I want to... | Use | Start with |
|---|---|---|
| Describe a mod in plain words and have it built for me | [REDagent](redagent/) | [Install and set up REDagent](redagent/install.html), then [your first mod](redagent/first-mod.html) |
| Install, switch on and off, and update mods made by others | [EDGEdeck](edgedeck/) | [Install EDGEdeck](edgedeck/install.html), then [your first mod](edgedeck/first-mod.html). Coming from Vortex? [Switch from Vortex](edgedeck/switch-from-vortex.html) |
| Script the game in TypeScript or JavaScript, or build an in-game app | [REDnode](rednode/) | [Making mods and apps](rednode/making-mods.html) |
| See how the game's own UI is built, or make a HUD panel that looks like the game's | [REDnode](rednode/) with its UI Tools pack | [UI Tools](rednode/ui-tools.html), then [your first native HUD panel](rednode/ui-tools-tutorial.html) |
| Browse the game's files and edit them, WolvenKit-style, in VS Code | [REDcode](redcode/) | [Install and set up REDcode](redcode/install.html) |
| Place objects in the game world and build a scene | [EDGEbuilder](edgebuilder/) | [Install and set up EDGEbuilder](edgebuilder/install.html) |
| Get the EDGE editor tools in one app | [EDGEkit](edgekit/) | [Install the app](edgekit/install.html), then [your first session](edgekit/first-session.html) |
| Install the EDGE tools in VS Code in one go | [EDGEkit](edgekit/) | [Install the extension pack](edgekit/install-pack.html) |
| Recolour clothes, or make a new material from my words | [EDGEmat](edgemat/) | [Install EDGEmat](edgemat/install.html) |
| Read the game's quests, or write a quest of my own | [EDGEquest](edgequest/) | [Install and set up EDGEquest](edgequest/install.html), then [Writing a quest](edgequest/writing.html) |
| Change one of the game's quickhacks, or make a new one | [EDGEhack](edgehack/) | [Install and set up EDGEhack](edgehack/install.html), then [your first quickhack](edgehack/first-quickhack.html) |
| Edit the game's sounds for a mod | [EDGEwave](edgewave/) | [Install and use EDGEwave](edgewave/try-it.html) |
| Make mods with Claude Code on my PC, step by step, with no code | [EDGEchat](edgechat/) | [Install and connect](edgechat/install.html), then [your first mod](edgechat/first-mod.html) |
| Let an AI agent on my PC read game files, manage mods or call the game | [REDnode](rednode/), [REDcode](redcode/), [EDGEdeck](edgedeck/), [EDGEmat](edgemat/) | [Connect Claude Code](connect-claude-code.html) |

## What you need

| You need | For |
|---|---|
| Cyberpunk 2077 on Windows PC | Everything. EDGE is single-player PC modding only. REDnode and REDagent support **game version 2.5** (REDnode 0.38.1 or later; REDagent 0.4.1 needs REDnode 0.50.2); on 2.31, use REDnode 0.37.0 and REDagent 0.3.1 |
| [VS Code](https://code.visualstudio.com/), or the [EDGEkit app](edgekit/install.html) | REDcode, EDGEdeck, EDGEmat, EDGEwave and the EDGEkit extension pack, which run inside it |
| [REDnode](rednode/install.html) installed in the game | REDagent, EDGEbuilder and any REDnode mod or overlay app |
| Your own [Anthropic API key](https://console.anthropic.com/) | REDagent. You pay Anthropic per use; see the [FAQ](faq.html#does-redagent-cost-money) |

> **Early days.** REDcode, EDGEdeck, EDGEmat, EDGEwave, EDGEquest and the EDGEkit extension pack install from the VS Code Marketplace or Open VSX as previews. REDnode, REDagent, REDbridge, EDGEbuilder and the EDGEkit app install from release files on GitHub. EDGEchat installs into Claude Code. Each tool's page in this wiki says how it installs today.
