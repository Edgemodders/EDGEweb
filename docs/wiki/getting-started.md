# Getting <span class="y">started</span>

EDGE is a family of tools. You don't need all of them. Start from what you want to do.

## I want to...

| I want to... | Use | Start with |
|---|---|---|
| Describe a mod in plain words and have it built for me | [REDagent](redagent/) | [Your first mod with REDagent](redagent/first-mod.html) |
| Install, switch on and off, and update mods made by others | [REDdeck](reddeck/) | [Switch from Vortex to REDdeck](reddeck/switch-from-vortex.html) |
| Script the game in TypeScript or JavaScript, or build an in-game app | [REDnode](rednode/) | [Making mods and apps](rednode/making-mods.html) |
| Browse the game's files and edit them, WolvenKit-style, in VS Code | [REDcode](redcode/) | [REDcode wiki page](redcode/) |
| Place objects in the game world and build a scene | [EDGEbuilder](edgebuilder/) | [Install and set up EDGEbuilder](edgebuilder/install.html) |
| Install the EDGE tools in VS Code in one go | [EDGEkit](edgekit/) | [Install the extension pack](edgekit/install-pack.html) |
| Edit the game's sounds for a mod (in development) | [EDGEwave](edgewave/) | [Try EDGEwave](edgewave/try-it.html) |
| Let an AI agent on my PC read game files, manage mods or call the game | [REDnode](rednode/), [REDcode](redcode/), [REDdeck](reddeck/) | [Connect Claude Code](connect-claude-code.html) |

## What you need

| You need | For |
|---|---|
| Cyberpunk 2077 on Windows PC | Everything. EDGE is single-player PC modding only |
| [VS Code](https://code.visualstudio.com/) | REDcode, REDdeck, EDGEwave and the EDGEkit extension pack, which run inside it |
| [REDnode](https://github.com/Edgemodders/REDnode) deployed to the game | REDagent, EDGEbuilder and any REDnode mod or overlay app |
| Your own [Anthropic API key](https://console.anthropic.com/) | REDagent. You pay Anthropic per use; see the [FAQ](faq.html#does-redagent-cost-money) |

> **Early days.** REDcode, REDdeck and the EDGEkit extension pack install from the VS Code Marketplace as previews. The other tools install from source or from a release file. Each tool's page in this wiki says how it installs today.
