# Get <span class="y">involved</span>

EDGEmodders is a new Cyberpunk 2077 modding community with one goal: **anyone can mod**. We build open-source, AI-first tools so a person with an idea can make a mod with an AI assistant, without first learning every file format and toolchain.

The community is just starting. Here is how to take part today.

## Where we are

| Place | Use it for |
|---|---|
| [github.com/Edgemodders](https://github.com/Edgemodders) | Source code, issues and pull requests for every tool |
| Issues in each repo | Bugs, feature ideas, "I got stuck here" reports |

More places to talk, such as a chat server, will be listed here when they open.

## Ways to help

### Never modded before

You are who these tools are for. Try them, then tell us:

- what you wanted to make,
- where you got stuck,
- what the assistant got wrong.

Open an issue in the repo of the tool you were using. A plain description is enough.

### Experienced modders

You know things no model knows yet: which records matter, which frameworks clash, what a clean mod looks like. Help by:

- reviewing how the tools handle the formats and frameworks you know,
- writing short guides an assistant can follow and a beginner can read,
- pointing out where we should use or credit existing community work.

### Tool builders

The stack is TypeScript, Node, VS Code extensions, C# (.NET) and MCP. Each repo has a `docs/dev-setup.md` with every install step.

| Repo | What it is | Language |
|---|---|---|
| [REDcode](https://github.com/Edgemodders/REDcode) | Modding IDE built on VS Code | TypeScript |
| [REDdeck](https://github.com/Edgemodders/REDdeck) | Mod manager inside VS Code | TypeScript |
| [REDbridge](https://github.com/Edgemodders/REDbridge) | WolvenKit engine host, JSON-RPC and MCP | C# |
| [REDnode](https://github.com/Edgemodders/REDnode) | Node.js runtime scripting for the game | C++, TypeScript |

## Ground rules

- **Be kind to beginners.** Every question is welcome. Nobody gets mocked for not knowing something.
- **Credit people.** Name the mods, tools and authors you build on. Respect each mod's license and its author's wishes.
- **AI is a tool, not an excuse.** You own what you publish. Test it, and say plainly when something is untested.
- **No piracy, no cheats for online play, no game files.** Never share files extracted from the game.
- **Respect the wider community.** WolvenKit, Nexus Mods and the framework authors made Cyberpunk modding possible. We work with them.
